
# ✨ Interactive Particle Animation

A modern and visually engaging particle animation project built using pure HTML, CSS, and JavaScript.  
This project creates smooth animated particles with interactive mouse effects, responsive behavior, and dynamic visual connections.

## 📌 Overview

The **Interactive Particle Animation** project demonstrates how HTML5 Canvas and JavaScript can be used to create beautiful real-time animations directly in the browser.

The particles move dynamically across the screen, interact with the cursor, and connect with nearby particles to create a futuristic animated background effect.

This project is lightweight, responsive, and beginner-friendly while still showcasing advanced frontend animation concepts.

# ⚙️ How It Works

The animation is rendered using the HTML5 Canvas API.

### Main Functionality:

1. Particles are generated randomly on the screen.
2. Each particle moves with its own velocity.
3. Nearby particles connect with animated lines.
4. Mouse movement creates interactive effects.
5. Canvas automatically adjusts on window resize.
